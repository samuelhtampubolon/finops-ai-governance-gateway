OWASP LLM & API Threat Mitigation

Defense-in-depth protection implemented directly at the gateway ingress layer.

🛡️ LLM01: Prompt Injection Firewall

Inspects prompts for instruction overrides, base64 smuggling, and system prompt extractors. Blocks attacks with HTTP 400 before model execution.

🔒 LLM06: Edge PII Scrubber

Automated edge sanitization replacing emails, Luhn-verified credit cards, SSNs, Indonesian NIKs, and API bearer keys with redaction placeholders.

🏢 API1: Multi-Tenant Cache Isolation

Strict partitioning of vector embedding search spaces by tenant_id. Guarantees that Tenant A can never retrieve cached responses generated for Tenant B.

⚡ API4: Denial-of-Wallet Circuit Breakers

Atomic spend tracking inside DuckDB. Automatically trips circuit breakers (HTTP 429) to preserve software gross margins above 75%.

Developer Integration & Quickstart

Interact with the FinOps Gateway using standard OpenAI-compatible client libraries or cURL.

Terminal / Bash Quickstart 
# 1. Clone repository & install dependencies
git clone https://github.com/samuelhtampubolon/finops-ai-governance-gateway.git
cd finops-ai-governance-gateway
pip install -r requirements.txt

# 2. Launch Gateway API (Port 8000) & Streamlit Cockpit (Port 8501)
python run_local.py

# 3. Issue a governed inference request
curl -X POST "http://localhost:8000/api/v1/gateway/chat/completions" \
  -H "Authorization: Bearer <TENANT_JWT_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "messages": [{"role": "user", "content": "How do I configure Single Sign-On with SAML?"}],
    "feature_tag": "customer_support",
    "force_refresh": false
  }'
